## Sobre o projeto

Este repositório contém meu portfólio pessoal, desenvolvido para reunir projetos e apresentar minha trajetória na área de desenvolvimento de software e inteligência artificial.

O site apresenta minhas competências técnicas, aplicações desenvolvidas e principais canais de contato profissional.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização, layouts responsivos e animações.
- **JavaScript:** interatividade e efeitos visuais.
- **Git e GitHub:** versionamento e hospedagem do código.
- **GitHub Pages:** publicação do site.

## Executando localmente

Para visualizar o projeto em sua máquina:

1. Clone o repositório:

```bash
git clone https://github.com/Leticiabarbosadev/portfolio.git
```

2. Acesse a pasta:

```bash
cd portfolio
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
